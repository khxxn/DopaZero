# DopaZero — YouTube 집중 모드

iPhone Safari의 **무료 Userscripts 앱**에서 사용하는 스크립트입니다. 설치할 파일은 `dopazero-youtube.user.js` 하나입니다. Mac이나 Apple 유료 개발자 계정이 필요하지 않습니다.

## 하는 일

- 홈 추천 피드를 숨기고 간단한 검색창을 표시합니다.
- 검색 결과·구독·채널·재생목록 등의 영상 카드에서 썸네일을 숨깁니다. 제목과 채널명은 남습니다.
- 영상 시청 페이지 아래의 관련·추천 영상 목록을 숨깁니다.
- Shorts 모음, Shorts 영상 카드, 하단 Shorts 버튼, 채널 Shorts 탭을 숨깁니다.
- 새로고침 없이 유튜브 안에서 이동하거나 추가 목록이 로드되어도 적용합니다.

영상 재생, 검색, 설명, 댓글, 구독 목록, 재생목록의 순서대로 보기는 사용할 수 있습니다. YouTube 앱에는 적용되지 않으며, Safari의 `m.youtube.com`, `www.youtube.com`, `youtube.com`에서 실행합니다. Shorts 직접 주소를 차단하거나 자동재생 설정을 바꾸지는 않습니다.

## 아이폰 설치 — 코드 수정 없이

1. App Store에서 무료 [Userscripts](https://apps.apple.com/kr/app/userscripts/id1463298887)를 설치합니다.
2. Userscripts 앱을 한 번 열어 **스크립트 저장 폴더**를 확인합니다. 최신 앱은 기본 로컬 폴더를 자동으로 지정합니다. 설치 파일을 찾기 쉽게 `나의 iPhone`의 로컬 폴더를 사용하세요.
3. **`dopazero-youtube.user.js`** 파일을 iCloud Drive나 파일 전송으로 아이폰에 옮깁니다. **파일 앱 → 이동**으로 2번의 폴더에 넣으세요. 파일 이름이 `.user.js.txt`로 바뀌지 않도록 합니다.
4. **설정 → 앱 → Safari → 확장 프로그램 → Userscripts**에서 확장을 켭니다. 이전 iOS에서는 `설정 → Safari → 확장 프로그램`입니다.
5. Safari에서 [유튜브 모바일](https://m.youtube.com/)을 엽니다. 주소창의 페이지 메뉴 → 확장 프로그램 → Userscripts를 열고 **이 웹사이트에서 항상 허용**을 선택합니다. `www.youtube.com`으로 이동하면 그 도메인에도 허용하세요.
6. Userscripts 목록에서 **DopaZero - YouTube 집중 모드**가 켜져 있는지 확인하고 페이지를 새로고침합니다.

설치 후 홈에서 **“보고 싶은 영상만.”** 검색창이 보이면 실행 중입니다.

## 끄기 / 업데이트 / 문제 해결

- **끄기:** Safari의 Userscripts 메뉴에서 이 스크립트를 끈 뒤 새로고침하세요. 페이지에 이미 적용된 변경은 새로고침해야 풀립니다.
- **업데이트:** 기존 파일을 새 파일로 교체한 뒤 Userscripts 메뉴를 한 번 열고 새로고침하세요. 여러 버전을 동시에 넣지 마세요.
- **아무 변화가 없을 때:** Safari로 열었는지, 파일 확장자가 정확한지, Userscripts가 읽는 폴더인지, 현재 YouTube 도메인에 권한이 있는지 확인하세요.
- **시크릿 브라우징:** 해당 모드에서도 Userscripts 사용이 허용되어 있어야 합니다.
- YouTube가 화면 구조를 바꾸면 일부 항목이 다시 보일 수 있습니다. 해당 페이지 주소와 어떤 항목이 남았는지 알려주면 선택자를 보완할 수 있습니다.

스크립트는 외부 라이브러리, 외부 전송, 분석 코드, 별도 서버, 계정 접근 API를 사용하지 않습니다. 화면 요소를 숨기는 기능이며, YouTube 자체의 데이터 요청·시청 기록을 차단하는 기능은 아닙니다.
