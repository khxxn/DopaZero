# DopaZero

유튜브의 추천 피드, 썸네일, Shorts를 가려 주는 아이폰 Safari용 유저스크립트입니다. 보고 싶은 영상은 직접 검색해서 찾도록 화면을 단순하게 만듭니다.

무료 앱 [Userscripts](https://apps.apple.com/kr/app/userscripts/id1463298887)만 있으면 됩니다. Mac이나 유료 개발자 계정은 필요 없고, 설치할 파일도 `dopazero-youtube.user.js` 하나입니다.

## 달라지는 것

- 홈에는 추천 영상 대신 검색창만 나옵니다.
- 검색 결과, 구독, 채널, 재생목록에서 썸네일이 빠집니다. 제목과 채널명은 그대로 보입니다.
- 썸네일과 함께 가려지던 영상 길이는 제목 아래 정보 줄 맨 앞에 글자로 보여 줍니다. 채널 홈 맨 위 영상에도 머리글과 길이·조회수·날짜를 붙여 아래 목록과 같은 모양으로 맞춥니다.
- 영상 아래에 붙는 관련·추천 영상 목록이 사라집니다.
- Shorts 선반과 영상, 하단 Shorts 버튼, 채널의 Shorts 탭이 보이지 않습니다.
- 새로고침 없이 페이지를 옮기거나 목록이 더 불러와져도 계속 적용됩니다.

영상 재생, 검색, 설명, 댓글, 구독 목록, 재생목록 순서대로 보기는 평소처럼 쓸 수 있습니다. Safari의 `m.youtube.com`, `www.youtube.com`, `youtube.com`에서만 동작하고 YouTube 앱에는 적용되지 않습니다. Shorts 주소로 바로 들어가는 것까지 막지는 않으며, 자동재생 설정도 그대로 둡니다.

## 아이폰에 설치하기

1. App Store에서 [Userscripts](https://apps.apple.com/kr/app/userscripts/id1463298887)를 받습니다.
2. Userscripts 앱을 한 번 열어 스크립트 저장 폴더를 확인합니다. 최신 버전은 기본 폴더를 알아서 정해 줍니다. 나중에 찾기 쉽도록 `나의 iPhone` 안의 폴더를 쓰는 편이 좋습니다.
3. `dopazero-youtube.user.js`를 iCloud Drive 등으로 아이폰에 옮기고, 파일 앱의 '이동'으로 2번 폴더에 넣습니다. 파일 이름 끝에 `.txt`가 붙지 않았는지 확인하세요.
4. 설정 → 앱 → Safari → 확장 프로그램에서 Userscripts를 켭니다. 예전 iOS에서는 설정 → Safari → 확장 프로그램에 있습니다.
5. Safari로 [m.youtube.com](https://m.youtube.com/)에 들어간 뒤 주소창의 페이지 메뉴 → 확장 프로그램 → Userscripts에서 '이 웹사이트에서 항상 허용'을 고릅니다. `www.youtube.com`으로 넘어가면 거기서도 한 번 더 허용합니다.
6. Userscripts 목록에서 'DopaZero - YouTube 집중 모드'가 켜져 있는지 보고 새로고침합니다.

홈에 “보고 싶은 영상만.”이라는 검색창이 보이면 설치가 끝난 것입니다.

## 끄기와 업데이트

- 끄기: Safari의 Userscripts 메뉴에서 스크립트를 끄고 새로고침합니다. 이미 열어 둔 페이지는 새로고침해야 원래대로 돌아옵니다.
- 업데이트: 폴더에 있는 파일을 새 파일로 바꾼 다음, Userscripts 메뉴를 한 번 열고 새로고침합니다. 예전 파일과 새 파일을 같이 두지 마세요.

## 안 될 때

- YouTube 앱이 아니라 Safari에서 열었는지 확인합니다.
- 파일 이름이 `.user.js`로 끝나는지, Userscripts가 읽는 폴더에 들어 있는지 봅니다.
- 지금 보고 있는 YouTube 주소에 Userscripts 권한을 줬는지 확인합니다.
- 개인정보 보호 브라우징에서 쓰려면 그 모드에서도 Userscripts를 허용해야 합니다.

YouTube가 화면 구조를 바꾸면 일부가 다시 보일 수 있습니다. 어느 페이지에서 무엇이 남았는지 알려 주시면 고치겠습니다.

이 스크립트는 화면에 보이는 모습만 바꿉니다. 외부 라이브러리나 서버를 쓰지 않고, 계정 정보에 접근하거나 어떤 정보도 밖으로 보내지 않습니다. YouTube가 주고받는 데이터나 시청 기록 자체를 막지는 않습니다.
